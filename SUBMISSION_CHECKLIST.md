# Submission Checklist

## Final submission review
- [ ] Public GitHub repository
- [ ] Complete README
- [ ] Hosted prototype
- [ ] Prototype tested in an incognito window
- [ ] Video pitch between 2 and 3 minutes
- [ ] Video accessible without requesting permission
- [ ] Official `*_predictions.csv` files
- [ ] Correct prediction filenames
- [ ] Correct column names and order
- [ ] Correct timestamp and prediction formats
- [ ] Correct number of prediction rows
- [ ] No accidental pandas index column
- [ ] No missing required predictions
- [ ] Short solution write-up
- [ ] Explanation of solution uniqueness
- [ ] Technology stack
- [ ] No API keys or secrets
- [ ] Backup copy of links and prediction files
- [ ] At least one member assigned to physical submission
- [ ] Final submission before 4:00 pm

> Warning: The prediction files must follow `Problem_Statement_3_Specifications.md` exactly. Do not guess the required CSV schema or field names. Validate the official format before submission.

## Quick pre-flight checks
- [ ] Data files were imported from the correct location.
- [ ] The output file names match the organisers’ requirement.
- [ ] The CSV columns match the official order exactly.
- [ ] Timestamp formatting is valid and consistent.
- [ ] The dashboard JSON and prediction CSV are separate outputs.
- [ ] All links are copied into a safe backup location.
- [ ] The solution write-up is short, readably structured and matches the final implementation.

## Final reminder
Before final submission, stop adding features, verify output files, check the hosted dashboard in a clean browser profile, and ensure the prediction files are ready for official evaluation.
