# Prediction Outputs

This folder will contain the official `*_predictions.csv` files produced for evaluation.

## Important notes
- Filenames and columns must follow the official PS3 specification.
- These CSV files are different from `dashboard_data.json`.
- Prediction CSV files are for formal evaluation.
- Dashboard JSON contains richer visualisation and explanation fields.
- Final files must be checked for row count, timestamps, column order, missing values, and accidental index columns.

Do not add raw datasets here. Only final evaluation outputs or clearly labelled intermediate prediction exports should appear in this folder.
