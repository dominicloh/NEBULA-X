# Input Data Folder

This folder is reserved for hackathon input CSV files only after checking the organisers’ instructions and the data-usage policy.

## Important reminders
- Raw data is ignored by Git by default via the repository `.gitignore`.
- Do not rename organiser-provided files unless a specific instruction requires it.
- The final pipeline should support one or more compatible input CSV files.
- Different CSV schemas cannot be processed automatically without explicit column mapping.
- Keep the raw files as provided until the team has validated the required schema and field meanings.
